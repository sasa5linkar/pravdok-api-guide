Get text from a scan

Upload a PDF or image and get its text back. Replace scan.pdf with your file. Read the words from the response’s text field.

POST/ocrmultipart form · returns JSON

What you get · abbreviated example

{
  "text": "Добар дан.",

  "page_count": 1

Use text for plain text, or markdown for formatted text when available. The actual words depend on your file.

Already-readable PDF text can be extracted directly. In mixed PDFs, scanned pages still go through OCR. OCR reads the source language; it does not translate it.

03

Translate text you already have

Replace Добар дан. with your text and choose the source and target languages. The example prints the translation. In the JSON response, find it under target_layer.segments.

POST/v1/translationsJSON body · returns a translation layer
SOURCE / sr-Cyrl

Добар дан.

↓
TARGET / en

Good day.

For English → Serbian, set source_language: "en" and choose target_language: "sr-Cyrl" for Cyrillic or "sr-Latn" for Latin script. Replace the source text too.

Multiple segments, names, numbers, and original values

Every segment needs a unique element_id, a string text, and a policy. Use the same ID to match the returned translation with its source.

PolicyWhat happens
translateTranslate the text into the target language.
transliterateConvert Serbian script without translating the meaning; useful for names.
preserveKeep the original text exactly.

Add "protected_values": ["INV-2026-42"] to keep an exact value present in a segment unchanged. The API also protects recognized identifiers and quantities. A request returns a complete layer or an error.

A request can contain up to 5,000 segments and 1,000,000 source characters. Keep each segment to translate under 24,000 characters. Supported directions are English → Serbian and Serbian → English.

1Create the job

This example translates a Serbian Cyrillic document into English. Set both language fields to match your task. The response is 202 Accepted, not the finished PDF.

Keep the returned job_id. You can poll it again later without uploading the document again. Progress percentages estimate the current stage; they are not a measurement of pages completed.

2 · Wait for completion, then 3 · download the PDF

Continue in the same session. The polling example stops on a terminal state or after 15 minutes. A client wait timeout does not cancel the server job.

completed and completed_with_warnings are success states. failed, cancelled, and expired are not. Check error_code if the job failed.

Artifact downloads need the same bearer token. The example uses the artifact’s relative download_url and checks its SHA-256. Download before the job’s expires_at time.

Change the workflow or inspect warnings

Omit both language fields to analyze without translation. Add render=false when you only want JSON artifacts. You can also submit existing canonical JSON through document_json, or an analysis ZIP through bundle, instead of file.

Review warning_count and download render-diagnostics.json when it is listed in artifacts. Text that cannot fit may leave the original region unchanged. The output is a flattened PDF; review the result before using it.

05

Need more control? Call each stage.

Use separate calls to inspect extracted text, choose what to translate, or render a particular language. Follow these three steps in the same session.

1 · Analyze a file → document.json

Returns structured document JSON with pages, text, boxes, and stable element IDs. This is the input expected by the following document-translation and rendering calls.

auto uses trustworthy native text and OCR where needed. native never runs OCR. ai requests OCR. hybrid combines native and OCR extraction. language_hint describes the source; it does not request translation.

Use asset_mode=bundle for a ZIP with the document and its page assets, or inline to embed assets in JSON. The example uses none and keeps the original file for rendering.

2 · Translate document.json → translation-response.json

Send the complete canonical JSON object in document. Keep its original IDs and source-language metadata. Send either document or segments in a translation request, never both.

For a subset, add element_ids. To treat selected elements differently, add policy_overrides, for example {"name_1":"preserve"} using an ID from your document. The short response from /ocr is not canonical document JSON.

3 · Render the translated layer → english.pdf

Send the original document_json, the selected layer_id, and the translation’s nested target_layer as layer_json. The complete translation response wrapper is not a render layer.

The uploaded source must be the unchanged file analyzed in step 1. Alternatively send its analysis ZIP as analysis_bundle; do not send both. auto uses replacement when matching source or verified backgrounds for every page are available, and reconstruction otherwise.

Check X-Document-Status and X-Document-Warnings. Use response_format=bundle to receive a ZIP with rendered.pdf, document.json, and diagnostics.json.

07

A few things that help

401 · Check the token

Use Authorization: Bearer … with the token for this server. Keep it in the header, not the URL.

400 / 422 · Check the request

Check field names, JSON types, language direction, and file format. Read the response’s detail message.

413 · The input is too large

Check the 25 MiB original-file limit and page/pixel limits. Split the source into smaller documents.

429 / 503 · Try again later

Wait for the number of seconds in Retry-After, if present. Try the health link. If it still fails, contact the API operator.

502 / 504 · A stage did not finish

Read detail. The model/converter may have failed or timed out. Try a smaller input; use jobs to track longer work.

404 / 409 · Check the job

The job or artifact may have expired, or the action conflicts with its state. Cancel a running job, then wait before deleting it.

Can I use the API from a browser or another computer?

Yes. Call the API from your application using the public HTTPS address and your access token. Browser access needs the operator to allow your page’s origin with OCR_CORS_ORIGINS. CORS is off by default. Command-line and Python requests do not need CORS.

Use https://pravdokapi.jerteh.rs as the API address. When sending files with JavaScript fetch and FormData, add the authorization header and let the browser set Content-Type automatically.

What should I check in the result?

Review OCR text for recognition errors and translations for meaning. Structured documents and rendered output include warnings; a successful response does not mean every region translated or fit on the page. Use the original document alongside the output when reviewing.

For jobs, read warning_count and the artifact list. For direct rendering, read X-Document-Status and X-Document-Warnings. Ask for a render bundle when you need diagnostics.
